# Agent Registry

Agents are role contracts, not individual model instances. Multiple
agents may use the same model with different instructions, tools,
permissions, and memory.

## Agent contract

Every agent must define:

- mission,
- responsibilities,
- inputs,
- outputs,
- tools,
- permissions,
- escalation conditions,
- review requirements,
- success criteria.

## Important

A role does not automatically receive all tools associated with its
department. Permissions are assigned explicitly.
