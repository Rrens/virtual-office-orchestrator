# Vision

## Product vision

Build a virtual AI company where specialized agents collaborate like a
real organization: planning work, researching problems, designing
solutions, building software, testing it, deploying it, selling it,
supporting customers, and learning from operational feedback.

## Long-term concept

A user should be able to provide a business objective such as:

> Build and launch a SaaS product for laundry businesses.

The company should transform that objective into a coordinated
organization:

``` text
Strategy
  -> Research
  -> Product
  -> Design
  -> Engineering
  -> Security
  -> Operations
  -> Marketing
  -> Sales
  -> Customer Support
  -> Analytics
```

The system should not blindly execute a fixed chain. It should select
the relevant departments and construct an appropriate workflow.

## Product principles

1.  **Goal first** — optimize for outcomes, not conversations.
2.  **Specialization** — agents have explicit responsibilities.
3.  **Orchestration over prompting** — coordination is a first-class
    system.
4.  **Tools over hallucination** — agents should inspect and act through
    tools.
5.  **Evidence over claims** — important outputs should reference
    artifacts, tests, logs, or sources.
6.  **Human control** — risky or externally consequential actions
    require approval.
7.  **Observable by default** — every meaningful action becomes an
    event.
8.  **Model-agnostic** — the organization should survive model changes.
9.  **Virtual office as visualization** — UI reflects system state
    rather than controlling it.
10. **Progressive autonomy** — start supervised and increase autonomy
    only where reliability is demonstrated.

## Success definition

The platform succeeds when a user can define a meaningful business goal
and observe a coherent chain of planning, execution, review, handoff,
and measurable output without manually coordinating every agent.
