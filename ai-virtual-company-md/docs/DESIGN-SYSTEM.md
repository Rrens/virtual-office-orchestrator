# Design System

## Principles

- Dense enough for operational dashboards.
- Clear status hierarchy.
- Consistent interaction patterns.
- Motion communicates state.
- Accessibility over decoration.

## Core tokens

Define:

- typography scale,
- spacing scale,
- border radius,
- elevation,
- surface hierarchy,
- status colors,
- department colors.

## Components

- Button
- Input
- Select
- Modal
- Drawer
- Card
- Table
- Tabs
- Badge
- Toast
- Timeline
- Task card
- Agent card
- Workflow node
- Approval dialog
- Event log

## Agent representation

Every agent should have:

- avatar,
- name,
- role,
- department,
- status indicator.

Department colors should be used consistently in dashboard and virtual
office.

## Accessibility

- Keyboard navigation.
- Visible focus states.
- Sufficient contrast.
- Text labels for status icons.
- Reduced-motion mode.
