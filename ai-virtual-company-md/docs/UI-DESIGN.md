# UI Design

The platform has two primary interfaces: operational dashboard and
virtual office.

## Dashboard

Primary navigation:

- Overview
- Projects
- Tasks
- Workflows
- Agents
- Departments
- Activity
- Artifacts
- Approvals
- Memory
- Observability
- Settings

## Project view

Show:

- objective,
- progress,
- workflow graph,
- active tasks,
- blockers,
- recent artifacts,
- agent activity,
- approvals.

## Agent detail

Show:

- role,
- status,
- current task,
- tools,
- permissions,
- recent runs,
- recent events,
- output artifacts,
- token and latency metrics.

## UX principles

- Status must be obvious.
- Errors must be actionable.
- Do not hide dependencies.
- Separate AI-generated claims from verified artifacts.
- Avoid decorative motion that obscures operational state.
